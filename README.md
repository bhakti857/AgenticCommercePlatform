# Agentic Commerce Platform
## Overview
The Agentic Commerce Platform is a comprehensive e-commerce solution built using .NET 8, ASP.NET Core Web API, EF Core 8, SQL Server, and Docker. The frontend is developed using React, TypeScript, Tailwind CSS, and Vite.
## Architecture
- Controllers + Services + Repositories
- JWT auth
- Agent Harness
## Database
- SQL Server (LocalDB or Docker)
