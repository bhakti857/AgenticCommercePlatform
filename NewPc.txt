⚙️ Step 2 – Set Up Environment Variables in Postman
Click the Environment dropdown (top right) → Manage Environments.

Click Add.

Name: AgenticCommerce Dev

Add these variables:

Variable	Initial Value	Current Value
baseUrl	http://localhost:5000	http://localhost:5000
token	(empty)	(will be filled after login)
Click Save and select this environment.

🔑 Step 3 – Test the Flow
1. Register a User
POST {{baseUrl}}/api/auth/register

json
{
  "email": "customer@example.com",
  "password": "Customer@123",
  "firstName": "John",
  "lastName": "Doe",
  "userType": 4
}
✅ Expected: 201 Created with a token.

2. Login
POST {{baseUrl}}/api/auth/login

json
{
  "email": "customer@example.com",
  "password": "Customer@123"
}
✅ Expected: 200 OK with a token.

3. Set the Token in Postman
After login, copy the token from the response:

Go to Environment Variables.

Paste the token into the token field.

Click Save.

Now all protected endpoints will automatically use this token (via Bearer {{token}}).

4. Get All Products (Protected)
GET {{baseUrl}}/api/products

✅ Expected: List of products.

5. Create an Order (Protected)
POST {{baseUrl}}/api/orders

json
{
  "items": [
    { "productId": 1, "quantity": 2 },
    { "productId": 2, "quantity": 1 }
  ]
}
✅ Expected: Order details with orderNumber.

6. Chat with AI Agent (Protected)
POST {{baseUrl}}/api/agent/chat

json
{
  "message": "Show me running shoes"
}
✅ Expected: A response from the mock agent.

📋 Quick Reference – Postman Endpoints
Method	Endpoint	Auth Required
POST	/api/auth/register	❌ No
POST	/api/auth/login	❌ No
GET	/api/products	✅ Yes
GET	/api/products/{id}	✅ Yes
POST	/api/products	✅ Yes (Admin)
GET	/api/orders	✅ Yes
POST	/api/orders	✅ Yes
POST	/api/agent/chat	✅ Yes
