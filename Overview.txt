📌 Project Overview
This solution provides a fully functional e‑commerce backend with:

Multi‑role user management (MasterAdmin, Admin, Employee, Customer)

Product catalog (CRUD, stock, categories)

Order processing with automatic stock deduction

JWT‑based authentication and role‑based authorization

AI agent harness (mock implementation ready to connect to real LLMs)

SQL Server database with Entity Framework Core migrations

Docker support (optional) for cross‑platform development



Key Features:

MasterAdmin: Complete system control and data visibility

Admin: Product management and employee oversight

Employees: Order processing and fulfillment

Customers: Profile management, browsing, and ordering
