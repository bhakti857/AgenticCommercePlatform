🗄️ Database Schema
Core tables:

Users – stores all users (discriminated by UserType: 1=MasterAdmin, 2=Admin, 3=Employee, 4=Customer)

Products – product catalog (SKU, name, price, stock, etc.)

Orders – order header (customer, totals, status)

OrderItems – line items (product, quantity, price snapshot)

Relationships:

Orders.CustomerId → Users.Id

OrderItems.OrderId → Orders.Id (cascade delete)

OrderItems.ProductId → Products.Id (restrict delete)

🔐 Authentication & Authorization
JWT tokens issued on login/register.

Claims: sub (UserId), email, UserType.

Custom policy for role‑based access (you can extend with permission claims).

All endpoints except /auth/register and /auth/login are protected with [Authorize].

🤖 AI Agent Harness (Mock)
The agent is built with Microsoft.Extensions.AI (preview).

MockChatClient implements IChatClient and returns simple keyword‑based responses.

AgentHarness manages session histories (in‑memory) and can be extended to call real LLMs (e.g., Azure OpenAI, Ollama).

The endpoint POST /api/agent/chat accepts a { "message": "..." } and returns a response
